The window stack (outer → inner)

Stage  "Log in"          ← OS window (title, size, position)
└── Scene (400 × 300)     ← canvas: one root + size + stylesheets
    └── root Node         ← start of the scene graph
        └── ...children   ← branch or leaf nodes

Layout panes — how children are positioned

PanePositions children by…Use when
BorderPane5 regions: top / bottom / left / right / centerApp shell with fixed edges + a flexible center
VBox / HBoxSingle column / row; spacing, padding, alignmentStacking a few controls (forms, toolbars)
StackPaneLayers children back-to-front (centered)Overlays: HUD on top of a map
AnchorPaneAnchors edges to offsets; else keeps top/leftAbsolute control, resizable edges
GridPaneRows × columns with optional spansAligned forms / grids
FlowPane / TilePaneWrap at boundary; uniform tiles for TilePaneWrapping rows of items
PaneNo layout — children sit at their own setX/setYAbsolute positioning (what this project often does)
