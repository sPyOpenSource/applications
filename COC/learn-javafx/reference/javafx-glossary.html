JavaFX Glossary

The shared vocabulary for this course. Every lesson uses these terms in exactly this sense.

TermMeaning
Application The entry-point base class. You override start(Stage); the framework calls it. One per launched app, via launch().
Stage The top-level OS window — title bar, position, size. The outermost layer. docs
Scene The canvas inside a Stage. Holds exactly one root node, plus width/height, fill, and stylesheets. docs
Scene graph The tree of nodes rooted at the Scene's root: the whole visual structure of a screen.
Node Base class for every visual item. Either a leaf or a branch. docs
Branch node A Parent: can hold children. Includes layout panes, Group, and controls.
Leaf node No children: ImageView, Text, Rectangle, MediaView, shapes.
Root node The single parentless node attached to a Scene.
Layout pane A Pane subclass that positions its children: AnchorPane, BorderPane, VBox, HBox, StackPane, GridPane, FlowPane, TilePane.
Control A ready-made, skinnable widget: Button, TextField, Label, …
getChildren() The ObservableList of a Parent's child nodes. Mutating it mutates the scene graph live.
id / styleClass CSS hooks on a node. id is unique (#text); styleClass is reusable (.button).
Stylesheet A CSS file attached to a Scene or Parent via getStylesheets().add(...).
FXML XML markup for building a scene graph declaratively. This project does not use it — everything is built in Java.
