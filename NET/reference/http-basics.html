HTTP Server Quick Reference

HTTP Request Format

METHOD URI HTTP/VERSION
Header1: value1
Header2: value2
...
[empty line]
[body if present]

Example:

GET /index.html HTTP/1.1
Host: localhost
Accept: text/html

HTTP Response Format

HTTP/VERSION STATUS REASON
Header1: value1
Header2: value2
...
[empty line]
[body]

Example:

HTTP/1.0 200 OK
Content-Length: 1234
Content-Type: text/html

<html>...</html>

Common HTTP Methods

MethodPurpose
GETRetrieve resource
POSTSubmit data to server
PUTUpdate/create resource
DELETEDelete resource
HEADLike GET but no body

Common Status Codes

CodeMeaning
200OK - Success
201Created
301/302Redirect
400Bad Request
401Unauthorized
404Not Found
500Internal Server Error

Socket Lifecycle (Server)

  1. ServerSocket(port) - Bind & listen
  2. accept() - Wait for connection → Socket
  3. getInputStream()/getOutputStream() - I/O
  4. Process request/response
  5. close() - Cleanup
