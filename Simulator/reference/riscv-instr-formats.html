RISC-V Instruction Formats

RV32I base — 6 instruction formats, fixed 32-bit length

Every RISC-V instruction is a 32-bit word with the opcode in the low 7 bits. The remaining bits encode registers, immediates, and function selectors. Six formats cover the entire base ISA:

R-type (register-register)

31:25   24:20   19:15   14:12   11:7    6:0
funct7  rs2     rs1     funct3  rd      opcode

Used by: ADD, SUB, SLL, SLT, XOR, OR, AND, MUL, DIV, etc.

Logic: reg[rd] = reg[rs1] OP reg[rs2] where funct7:funct3 selects the operation.

I-type (immediate / load)

31:20       19:15   14:12   11:7    6:0
imm[11:0]   rs1     funct3  rd      opcode

Used by: ADDI, SLTI, XORI, ORI, ANDI, SLLI, SRLI, SRAI, LB, LH, LW, LBU, LHU, JALR

Logic: reg[rd] = reg[rs1] OP sext(imm[11:0]). The 12-bit immediate is sign-extended to 32 bits.

S-type (store)

31:25       24:20   19:15   14:12   11:7    6:0
imm[11:5]   rs2     rs1     funct3  imm[4:0] opcode

Used by: SB, SH, SW

Logic: mem[reg[rs1] + sext(imm)] = reg[rs2]. The immediate is split between bits 31-25 and 11-7.

B-type (branch)

31:25       24:20   19:15   14:12   11:7    6:0
imm[12|10:5] rs2    rs1     funct3  imm[4:1|11] opcode

Used by: BEQ, BNE, BLT, BGE, BLTU, BGEU

The immediate encodes a signed offset in multiples of 2 (bit 0 is always 0).

// Decoding from IsaSim.java:321
int imm = (((instr >> 8) & 0xF) << 1)
        | (((instr >> 25) & 0x3F) << 5)
        | (((instr >> 7) & 0x1) << 11)
        | ((instr >> 31) << 12);
if ((imm >> 11) == 1) imm |= 0xFFFFE000; // sign-extend

U-type (upper immediate)

31:12       11:7    6:0
imm[31:12]  rd      opcode

Used by: LUI, AUIPC

Logic: reg[rd] = imm << 12 (LUI) or reg[rd] = pc + (imm << 12) (AUIPC).

J-type (jump)

31:12            11:7    6:0
imm[20|10:1|11|19:12] rd      opcode

Used by: JAL

// Decoding from IsaSim.java:282
int imm = (((instr >> 21) & 0x3FF) << 1)
        | (((instr >> 20) & 0x1) << 11)
        | (((instr >> 12) & 0xFF) << 12)
        | ((instr >> 31) << 20);
if ((instr >> 31) == 1) imm |= 0xFFF00000; // sign-extend
reg[rd] = pc + 4;
pc += imm;
