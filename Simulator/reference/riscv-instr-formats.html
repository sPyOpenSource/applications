RISC-V Instruction Formats

RV32I base — 6 instruction formats, fixed 32-bit length

src/jCPU/RiscV/RVConstants.java — opcode constants

Every RISC-V instruction is a 32-bit word with the opcode in the low 7 bits. The remaining bits encode source/destination registers, immediates, and function selectors that qualify the operation. Six formats cover the entire base ISA.

Instructions: SB, SH, SW

mem[reg[rs1] + sext(imm)] = reg[rs2] — the immediate is split between bits 31–25 and 11–7, then reassembled.

// Decoding from IsaSim.java:425
int imm = ((instr >> 7) & 0x1F) | ((instr >> 25) << 5);
if ((instr >> 31) == 1) imm |= 0xFFFFF000;  // sign-extend
int memAddr = reg[rs1] + imm;
int memValue = reg[rs2];
switch (funct3) {
    case 0x0: code.write(memAddr, memValue & 0xFF); break;        // SB
    case 0x1: code.write16(memAddr, (short)(memValue & 0xFFFF)); break; // SH
    case 0x2: code.write16(memAddr, (short)memValue); break;       // SW
}

Instructions: BEQ, BNE, BLT, BGE, BLTU, BGEU

The immediate encodes a signed offset in multiples of 2 (bit 0 of the offset is always 0, so it is not stored). The funct3 selects the comparison condition.

// Decoding from IsaSim.java:321
int imm = (((instr >> 8) & 0xF) << 1)       // imm[4:1]
        | (((instr >> 25) & 0x3F) << 5)     // imm[10:5]
        | (((instr >> 7) & 0x1) << 11)      // imm[11]
        | ((instr >> 31) << 12);            // imm[12] (sign)
if ((imm >> 11) == 1) imm |= 0xFFFFE000;    // sign-extend

Instructions: LUI, AUIPC

LUI: reg[rd] = imm << 12 — loads the 20-bit immediate into the upper bits of rd, lower 12 bits are zero.

AUIPC: reg[rd] = pc + (imm << 12) — adds the shifted immediate to the current PC.

Instructions: JAL

reg[rd] = pc + 4 (return address), then pc += offset. The 21-bit immediate stores a signed offset in multiples of 2, split across 4 bit-groups in the instruction word.

// Decoding from IsaSim.java:282
int imm = (((instr >> 21) & 0x3FF) << 1)    // imm[10:1]
        | (((instr >> 20) & 0x1) << 11)     // imm[11]
        | (((instr >> 12) & 0xFF) << 12)    // imm[19:12]
        | ((instr >> 31) << 20);            // imm[20] (sign)
if ((instr >> 31) == 1) imm |= 0xFFF00000;  // sign-extend
reg[rd] = pc + 4;
pc += imm;

Field extraction cheat sheet

The bit-manipulation patterns appear identically across every handler. Internalise these:

int rd     = (instr >> 7)  & 0x1F;  // bits 11–7  → 5-bit destination register
int rs1    = (instr >> 15) & 0x1F;  // bits 19–15 → 5-bit source register 1
int rs2    = (instr >> 20) & 0x1F;  // bits 24–20 → 5-bit source register 2
int funct3 = (instr >> 12) & 0x7;   // bits 14–12 → 3-bit function selector
int funct7 = (instr >> 25);         // bits 31–25 → 7-bit function selector

// Sign-extension idiom for 12-bit immediate
int imm12 = (instr >> 20);
if ((imm12 >> 11) == 1) imm12 |= 0xFFFFF000;
