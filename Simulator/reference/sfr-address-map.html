    ↑ called by
MCS51.sfr(int add, int value)     // high-level
    ↑ called by
MCS51.setDirect(address, value)   // instruction execution

Peripheral Skeleton

class MyPeripheral extends JPanel
    implements MCS51Peripheral, SfrWriteListener {

    private MCS51 cpu;

    @Override
    public void registerCpu(MCS51 cpu) {
        this.cpu = cpu;
        cpu.addSfrWriteListener(MY_ADDR, this);
    }

    @Override
    public void sfrWrite(int register, int value) {
        // handle the write
    }
}

Register in CPU class:

addPeripheral(new MyPeripheral());
