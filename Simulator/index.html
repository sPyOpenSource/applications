Engine Internals Course

Understanding JavaScript & Python Engine Internals

📚 Course Overview

This course takes you from interpreter fundamentals to production engine internals. Each lesson builds on the previous one.

📖 Lessons

  1. Interpreter Architectures

    Tree-walking → Bytecode VM → JIT Compilation. The spectrum of execution models and why modern engines combine all three.

  2. V8 Architecture Deep Dive

    Ignition interpreter, TurboFan compiler, hidden classes, inline caching, deoptimization, Orinoco GC.

  3. SpiderMonkey & JavaScriptCore

    Baseline interpreter, IonMonkey/WarpBuilder, type inference, incremental GC.

  4. CPython Internals

    Bytecode VM (ceval.c), reference counting + generational GC, GIL, memory allocator, frames.

  5. PyPy & Meta-Tracing JIT

    RPython, meta-tracing, how PyPy's JIT differs from V8's approach.

  6. Advanced Topics
  7. Inline caching, polymorphic inline caches, speculative optimization
  8. Deoptimization / On-Stack Replacement (OSR)
  9. WebAssembly integration, WASM GC, SIMD
  10. Security: JIT spraying, type confusion, Spectre mitigations
