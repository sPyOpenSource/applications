# Learning Path & Resources

## After the series (next steps)
1. **Build 2-3 projects** (portfolio): CLI app → REST API.
2. **WebSockets** (backend): controllers, services, REST.
3. **Build tools:** Ant.
4. **Version control:** Git + GitHub.
5. **Testing:** JUnit 4.
6. **Databases:** SQL database.
7. **Optional:** data structures & algorithms.

## Recommended resources
- Official Java docs: docs.oracle.com/javase
- Practice: Exercism (Java track), LeetCode easy
- Books: "Head First Java", "Effective Java" (Bloch)
- IDE: NetBean

## Companion repo conventions
- Folder per episode: `epNN-slug/`
- Each folder: `Main.java` (or project) + `NOTES.md` (key takeaways + homework solution)
- Tag releases per season: `v1.0-season1`, etc.
- README with setup instructions.

## Metrics to track per video
- CTR, AVD (average view duration), retention curve, subs gained.
- Re-shoot intro if first-30s retention < 70%.
