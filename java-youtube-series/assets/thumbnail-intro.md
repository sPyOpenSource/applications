# Thumbnail & Branding Ideas

## Thumbnail formula (per video)
- Background: dark `#1E1E2E`
- Big text (3-5 words): the topic, e.g. "CLASSES & OBJECTS"
- Accent: code snippet or icon in Java orange `#F89820`
- Face: expressive (surprised/pointing) in bottom-right
- Small badge: episode number "EP 09"

## Title templates
- `Java #N — <Topic> (Java from Zero to Hero)`
- Shorts: `Java in 60s: <topic>`

## Intro (5s) script
"Java from Zero to Hero. Episode N. Let's code."

## Outro (15s) script
"If this helped, hit subscribe — new episodes every Tuesday and Friday. Next up: <next topic>. Code is in the description. See you there."

## End screen layout
- Left: subscribe button
- Right: next video card
- Bottom: "Full playlist" card

## Channel about
"Learn Java from absolute zero to building real projects. Free, code-first, no fluff. New videos Tue & Fri."

## Socials / links
- GitHub repo (companion code)
- Discord community
- Newsletter (optional)
