# Java from Zero to Hero — YouTube Series

A complete, beginner-friendly YouTube series that teaches **Java programming from scratch** to building a real project. 30 episodes across 4 seasons, ~10–15 min each.

## Series Identity

- **Title:** Java from Zero to Hero
- **Tagline:** Learn Java by building. No fluff, just code.
- **Target audience:** Absolute beginners to programming, plus devs switching to Java.
- **Prerequisites:** None. A laptop + internet.
- **Tone:** Friendly, encouraging, code-first. Show, don't just tell.
- **Format per episode:** Hook (30s) → Concept (3m) → Live coding (7m) → Recap (1m) → Homework (30s)
- **Visuals:** Screen recording of IntelliJ IDEA, terminal, occasional diagrams (Excalidraw). Face-cam in corner for personality.
- **Code repo:** companion GitHub repo with one folder per episode (`ep01-hello-world`, ...).

## Seasons

| Season | Episodes | Topic |
|---|---|---|
| 1 | 1–8 | Java Basics |
| 2 | 9–16 | Object-Oriented Programming |
| 3 | 17–24 | Advanced Java: VFS and Networking |
| 4 | 25–30 | Projects with AI: AI Agent |

## Branding assets

- **Intro (5s):** logo animation + "Java from Zero to Hero"
- **Outro (15s):** subscribe CTA + next-episode teaser + social links
- **Thumbnail style:** dark background, big bold title, code snippet accent, expressive face
- **Color palette:** `#1E1E2E` (bg), `#F89820` (Java orange), `#5382A1` (Java blue), `#FFFFFF` (text)

## Publishing cadence

- 2 episodes/week (Tue & Fri) for consistency.
- Community posts between uploads (polls, code snippets).
- Shorts: 1 tip/week clipped from long-form.

## Success metrics

- Watch time > 50%, CTR > 5%, subscriber conversion > 2%.
- Track per-episode retention; re-shoot low-retention intros.
