# Per-Video Upload Checklist

Before publishing each episode:

- [ ] Video exported 1080p60, audio normalized
- [ ] Captions reviewed (auto + manual)
- [ ] Thumbnail (1280x720) uploaded
- [ ] Title follows template `Java #N — <Topic> (Java from Zero to Hero)`
- [ ] Description includes: hook, timestamps, repo link, socials, previous/next video
- [ ] Tags added (java, java tutorial, learn java, java programming, java for beginners, oop, <topic>)
- [ ] End screen + cards configured
- [ ] Pinned comment with engagement question
- [ ] Companion code pushed to repo (`epNN-slug/`)
- [ ] Community post scheduled (poll or snippet)
- [ ] Added to playlist "Java from Zero to Hero"
