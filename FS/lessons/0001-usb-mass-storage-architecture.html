The Big Picture

When you plug in a USB flash drive, your OS sees a block device — something you can read/write in fixed-size sectors (usually 512 or 4096 bytes). But USB itself doesn't speak "blocks." It speaks bulk endpoints.

USB Mass Storage Class (MSC) bridges this gap. It defines how to tunnel SCSI commands over USB bulk endpoints.

Key insight: MSC is a protocol adapter. It takes SCSI commands (designed for parallel SCSI buses) and transports them over USB bulk pipes.

Three Layers

┌─────────────────────────────────────┐
│        File System (FAT/exFAT)      │  ← You implement this
│   Logical blocks (LBAs), clusters   │
├─────────────────────────────────────┤
│      Block Device Driver (You)      │  ← Translates FS ops → SCSI
│   READ(10), WRITE(10), INQUIRY...   │
├─────────────────────────────────────┤
│    USB Mass Storage Class (MSC)     │  ← Bulk-Only Transport (BOT)
│   CBW → Data → CSW handshake        │
├─────────────────────────────────────┤
│         USB Bulk Endpoints          │  ← USB 2.0 Chapter 9
│   EP OUT (host→dev), EP IN (dev→host)│
└─────────────────────────────────────┘

What You Need to Implement

As a USB host implementing a file system, you own the "Block Device Driver" layer. Your job:

  1. Enumerate the device, find the MSC interface (class 0x08, subclass 0x06, protocol 0x50)
  2. Claim the bulk IN and bulk OUT endpoints
  3. Implement BOT: wrap SCSI commands in Command Block Wrappers (CBW), send data, receive Command Status Wrappers (CSW)
  4. Implement SCSI commands: INQUIRY, REQUEST SENSE, TEST UNIT READY, READ CAPACITY, READ(10), WRITE(10), SYNCHRONIZE CACHE
  5. Present a block interface to your file system: read_blocks(lba, count, buf), write_blocks(lba, count, buf)

The SCSI Commands You'll Use

Command Opcode Purpose
INQUIRY 0x12 Identify device, get vendor/product strings
REQUEST SENSE 0x03 Get error details after a failed command
TEST UNIT READY 0x00 Check if media is present and ready
READ CAPACITY(10) 0x25 Get sector count and sector size
READ(10) 0x28 Read sectors (LBA + count)
WRITE(10) 0x2A Write sectors (LBA + count)
SYNCHRONIZE CACHE(10) 0x35 Flush device write cache
