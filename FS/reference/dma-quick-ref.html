Alignment Requirements (UHCI)

  • Transfer Descriptor (TD): 16-byte alignment, 32 bytes
  • Queue Head (QH): 32-byte alignment, 32 bytes
  • Frame List: 4KB alignment, 4KB (1024 × 4 bytes)

Common Bugs Checklist

  • ☐ Using malloc/kmalloc instead of dma_alloc_coherent for TD/QH
  • ☐ Missing dma_map_single before submitting buffer to controller
  • ☐ Missing dma_unmap_single after completion
  • ☐ Wrong DMA direction flag
  • ☐ Missing cache clean/invalidate on bare metal
  • ☐ Wrong alignment (TD=16B, QH=32B, Frame List=4KB)
  • ☐ Using virtual address where DMA address required
  • ☐ Buffer crosses 64KB boundary (some controllers)
  • ☐ Buffer in non-DMA-accessible memory region

Debug Output Interpretation

DEBUG createTDs: dataBuffer size=31 start=0x13DB2000
DEBUG createTDs: pipe.rm=
TD created=TD[00000001, 39800000, 03C08169, 13DB2000->null]
  • start=0x13DB2000 — virtual address of data buffer
  • 0x13DB2000 in TD field 3 — buffer pointer (should be DMA address)
  • ->null — link pointer (end of chain)
