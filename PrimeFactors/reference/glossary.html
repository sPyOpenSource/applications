Glossary

Terms used in the PrimeFactors codebase and related literature.

Notation

n (or N) — The integer being factored.
p, q — Prime factors of n (so n = p · q).
a, b — Usually: a2 ≡ b2 (mod n).
ℤn — The ring of integers modulo n.
𝔽p — The finite field of order p.
(a/p) — The Legendre symbol: +1 if a is a quadratic residue mod p, −1 otherwise.

A–Z

congruence of squares

A relation x2 ≡ y2 (mod n) where x ≠ ±y (mod n). When such a relation holds, gcd(x − y, n) yields a nontrivial factor of n. The central building block of all modern factoring algorithms.

ECM (Elliptic Curve Method)

A factoring algorithm due to H. W. Lenstra Jr. (1987) that uses elliptic curves over ℤn to find a factor p. The algorithm picks a random curve and point, then computes a scalar multiple k·P modulo n using the curve's group law. If k·P succeeds modulo n but fails modulo p (because the group order #E(𝔽p) divides k), the failure reveals p via a gcd operation. Implemented in the ecm/ package.

exponent vector

For an integer m factored as ∏ piei, the vector (e1, e2, …, ek) of exponents. Multiplying numbers corresponds to adding their exponent vectors. A number is a square iff every exponent is even. For factoring we reduce exponents modulo 2, turning the problem into linear algebra over the field 𝔽2.

factor base

A set B = {p1, p2, …, pk} of small primes. An integer is B-smooth if all its prime factors lie in B. The QS factor base includes only primes for which n is a quadratic residue (so x2 ≡ n (mod p) has solutions), which ensures the polynomial g(x) = (x + ⌈√n⌉)2 − n can factor smoothly over B.

Legendre symbol

For odd prime p and integer a, (a/p) = a(p−1)/2 mod p, taking value 1 (quadratic residue), −1 (non-residue), or 0 (p divides a). Used in MathUtils.isRootInQuadraticResidues() to test whether n is a quadratic residue modulo a candidate factor base prime.

quadratic residue

An integer a is a quadratic residue modulo p if the congruence x2 ≡ a (mod p) has a solution. For QS, we need n to be a quadratic residue modulo each factor-base prime p, so that the sieving polynomial can attain values ≡ 0 (mod p).

QS (Quadratic Sieve)

A general-purpose factoring algorithm invented by Carl Pomerance (1981). It sieves over values of a quadratic polynomial g(x) = (x + ⌈√n⌉)2 − n, collecting those that factor completely over a chosen factor base. The exponent vectors of these B-smooth values form a matrix; dependencies in that matrix (over 𝔽2) produce a congruence of squares. The variant in this codebase is the Self-Initializing Quadratic Sieve (SIQS), which re-initializes the polynomial periodically to cover more of the search space. Implemented in com/gazman/factor/.

RESSOL (Tonelli–Shanks / modular square root)

An algorithm for solving x2 ≡ n (mod p) for an odd prime p. Implemented in MathUtils.ressol(). The two solutions r and p − r give the starting offsets for the sieving wheel for each factor-base prime.

sieving

The process of adding log2(p) contributions at arithmetic progressions in an array, to identify indices where a polynomial value is likely B-smooth. Rather than trial-dividing each candidate, QS accumulates log-p approximations and selects candidates whose total log approaches log(g(x)). This replaces expensive factorization attempts with fast integer addition. Implemented via the Wheel class.

smooth (B-smooth)

An integer is B-smooth if all its prime divisors are ≤ B. The QS relies on g(x) = (x + ⌈√n⌉)2 − n being B-smooth with probability high enough to collect ~B + ε relations in polynomial time. Smoothness probability determines the optimal factor-base size.

SIQS (Self-Initializing Quadratic Sieve)

An improved variant of QS that replaces the single polynomial g(x) = (x + ⌈√n⌉)2 − n with a family of polynomials ga(x) = (ax + b)2 − n, where a is chosen as a product of factor-base primes and b is a modular square root. This allows the sieve to sample from many different arithmetic progressions, increasing the density of smooth values. This is what Gazman's code implements.

wheel (sieving wheel)

In this codebase, a Wheel tracks the current positions in the sieve array for a given factor-base prime. For each prime p, the wheel stores the two offsets (from Tonelli–Shanks) and advances by p each step, producing indices where p divides g(x). It accumulates log(p) contributions to approximate trial division. Implemented in Wheel.java.

GCD (Greatest Common Divisor)

The largest integer dividing both inputs. In factoring, gcd(a, n) extracts a factor when a shares a divisor with n. Computed via the Euclidean algorithm. Used in testSolution() to extract factors from a candidate congruence of squares.

nullspace / kernel (over 𝔽2)

The set of vectors v such that M·v = 0 (mod 2). Each such vector identifies a subset of relations whose exponent vectors sum to zero modulo 2 — meaning the product of the corresponding y-values is a perfect square. Found via Gaussian elimination on the transpose in BitMatrix.solve().
